ATTL (MU) - Website package
===========================
Files included:
- index.html, about.html, products.html, contact.html
- assets/style.css, assets/christian.jpg

How to use:
1. Upload the entire folder to GitHub Pages (create repo famous-rock.github.io or similar) or any static host.
2. Open products.html in your browser. Use the 'Add Product' form to add products. They are saved locally in your browser (LocalStorage).
3. To edit site text, open the .html files in a text editor and edit content. No server required.
4. Contact form uses mailto: to open your email client. For automated forms, integrate a service (Formspree) and update form action in contact.html.

Notes for non-technical users:
- Using GitHub Pages: create a new repository, upload all files, enable Pages from main branch. Your site will be at https://<username>.github.io/<repo> or if repo named <username>.github.io it will be root.
- Images added to products are stored in your browser only; they are not uploaded to a server. If you clear browser data they will disappear.
